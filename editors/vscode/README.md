# pymodelica Simulation Scope (VS Code)

An interactive chart of the pymodelica model corpus, simulated to its reference points, inside
VS Code. Same chart engine as the notebook widget (`modelica.sim.view`): drag to zoom,
double-click to reset, hover for a cursor readout, click a variable to toggle it, and switch
the vertical axis between linear, `log |y|`, and normalised. Reference points are drawn as
rings the trajectory passes through.

Plain JavaScript, no build step, no dependencies.

## Install it locally

Pick one:

**Run it from source (fastest):**
1. Open this folder (`editors/vscode`) in VS Code.
2. Press `F5`. A second VS Code window ("Extension Development Host") opens with the extension loaded.
3. In that window: `Cmd/Ctrl+Shift+P` → **pymodelica: Open Simulation Scope**.

**Package and install a `.vsix`:**
```bash
cd editors/vscode
npx --yes @vscode/vsce package        # writes pymodelica-scope-0.0.1.vsix
code --install-extension pymodelica-scope-0.0.1.vsix
```
Then `Cmd/Ctrl+Shift+P` → **pymodelica: Open Simulation Scope** in any window.

**Or drop the folder in place:**
```bash
cp -r editors/vscode ~/.vscode/extensions/pymodelica-scope-0.0.1
```
Reload VS Code.

## Refreshing the data

`media/scope.data.json` is a snapshot generated by the Python simulator (`modelica.sim`), not
compiled per model. Regenerate it from the corpus and the chart updates -- see the project's
scope-data generator. The webview never compiles anything; it reads the data and draws it.
